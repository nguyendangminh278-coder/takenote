# HAN Study — University Learning Hub

Static bilingual study dashboard for Fall 2026. Open `index.html` directly in a browser; no build step is required.

## Included modules

- Semester dashboard and timetable for six courses.
- Data Mining Session 01 pre-reading: core concepts, CRISP-DM, textbook, Lab 0 setup, progress checklist and quiz.
- Database Management Session 01–02 review: ERM/ERD concepts and the Sweet Home exercise.
- Local source PDFs in `docs/` and official external learning resources.
- Vietnamese / English toggle and locally saved checklist progress.
